# 🚆 Railway Reservation System Analysis Dashboard – Power BI

An interactive Railway Reservation Analytics Dashboard built using Power BI, SQL, and MySQL to analyze passenger bookings, train performance, revenue generation, payment trends, and overall railway operations.

---

# 🚀 Project Overview

This project transforms raw railway reservation data into meaningful business insights through interactive dashboards and visual analytics.

The dashboard helps railway management understand:

* Booking trends and passenger behavior
* Revenue performance across trains
* Payment method preferences
* Train popularity and occupancy trends
* Booking status distribution
* Operational performance metrics

---

# ✨ Dashboard Features

## 📌 KPI Metrics

Track important railway performance indicators including:

* 🎫 Total Bookings
* 👥 Total Passengers
* 🚆 Total Trains
* 💰 Total Revenue
* 💳 Average Ticket Price

---

## 📍 Booking Analysis

Analyze reservation trends across:

* Train Names
* Booking Status
* Travel Dates
* Passenger Demographics
* Payment Methods

---

## 📈 Revenue Analysis

Gain insights into:

* Revenue by Train
* Revenue by Payment Method
* Revenue Trends Over Time
* Average Ticket Value

---

## 🚆 Train Performance Analysis

Monitor train-related metrics such as:

* Most Popular Trains
* Total Bookings per Train
* Train Capacity Utilization
* Schedule Performance

---

## 🎛️ Interactive Dashboard

Users can dynamically explore data using:

* Train Filters
* Booking Status Slicers
* Payment Method Filters
* Passenger Demographic Filters
* Interactive Visual Exploration
